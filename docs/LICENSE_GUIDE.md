# 哪份是我们自己的许可？ / Which license is ours?

[中文README](../README.zh-CN.md) · [English README](../README.md)

## 中文

**奶家族自己的许可证已经创建，就是仓库根目录的 [LICENSE](../LICENSE)。**

- 采用标准 **MIT License**。
- 项目署名：**Copyright (c) 2026 Milk Family contributors**。
- 适用范围：奶家族源码和文字文档。具体权限、声明保留及免责条件以LICENSE原文为准。

MIT是一种通用的软件开源许可，每个项目可以在自己的版权声明下采用。根目录LICENSE是奶家族的独立许可文件，项目署名与上游声明分别保留。

另外还有两类独立文件：

| 文件 | 作用 |
| --- | --- |
| [ASSET_RIGHTS.md](../ASSET_RIGHTS.md) | 人物、卡片、动画、图标、截图和预览媒体的范围说明；这些美术不自动进入源码MIT许可。 |
| [licenses/PokeTokenBar-MIT.txt](../licenses/PokeTokenBar-MIT.txt) | 保留参考项目PokeTokenBar的上游软件声明，署名为chattymin。它不是奶家族的主许可证，也不是宝可梦图片或角色的使用授权。 |
| [NOTICE.md](../NOTICE.md) | 解释参考来源与保留上游声明的原因。 |

README把“我们自己的许可”和“上游致谢”分开列出。公开美术包前仍要核实所含设计的展示及分发范围，源码选择MIT本身不能替代素材授权。

## English

**Milk Family has its own license: the root [LICENSE](../LICENSE).** It adopts standard MIT terms with **Copyright (c) 2026 Milk Family contributors** and covers this project’s source code and written documentation. The license text defines its permissions, notice requirements and warranty terms.

MIT is a reusable software-license format. Different projects can each adopt it under their own copyright notice; sharing the license name does not make this project another project’s work.

[ASSET_RIGHTS.md](../ASSET_RIGHTS.md) separately describes artwork and media. [PokeTokenBar-MIT.txt](../licenses/PokeTokenBar-MIT.txt) preserves the upstream software notice credited to chattymin. It is not Milk Family’s main license or a grant to use Pokémon designs. [NOTICE.md](../NOTICE.md) explains the reference.

The README therefore separates our project license from upstream acknowledgment. Public display and distribution of runtime artwork must be cleared separately from the source-code license.
