# Contributing

Run `./scripts/check.sh` before proposing a change. With an authorized runtime pack, also run `./scripts/check.sh --with-assets`. Include the affected macOS version, app version, reproduction steps and checks in the pull request.

Keep real Token accounting separate from game bonuses. Do not commit saves, usage logs, prompts, API keys, signing credentials, generated apps, full runtime artwork or personal paths. Add both languages when changing user-facing labels. Preserve existing save compatibility and accessibility motion preferences.

提交前运行源码检查；有授权运行素材时补跑资源检查。用量账本与游戏奖励必须分开，新文案应提供中英两种语言。不要提交真实存档、日志、密钥、签名凭证或完整运行美术。
